# 预告丨5月21日上午，广西医科大一附院开展第17届国际甲状腺知识宣传周义诊活动

> 更新时间：2026-09-17 (UTC+8)

甲状腺疾病是一种常见的内分泌系统疾病，近年来发病率逐年上升，对患者生活质量和健康造成严重影响。2025年5月25日至31日是第十七届国际甲状腺知识宣传周活动，今年宣传周的主题为“甲状腺疾病与AI”。
5月21日上午，我院特别举办“第17届国际甲状腺知识宣传周：早筛早治，守护‘生命腺’——甲状腺疾病需全程管理！”义诊活动，诚邀广大群众前来参与，了解甲状腺疾病全程化管理知识，推动甲状腺疾病诊疗工作迈向新高度。

**义诊时间与地点**
◆2025年5月21日 9:00-11:00

◆广西医科大学第一附属医院门诊一楼大厅

**义诊内容**
1. 由胃肠腺体外科、内分泌科、核医学科、超声医学科、病理科组成的专家团队，为患者现场解答甲状腺疾病的相关问题；

2. 免费甲状腺超声筛查（限前30名）；

3. 免费发放甲状腺疾病相关知识的宣传手册；

4. 免费测量血压、测血糖（限前150名）；

5. 健康知识展板：如“甲状腺结节超声分级标准”、“甲状腺细胞病理学报告系统”。

**温馨提示**
1.如有相关病历资料，请携带到义诊现场。

2.一对一问诊，避免扎堆拥挤，保持1米距离。
