# 强刊兴学丨国际学术期刊Current Urology获得首个影响因子

> 更新时间：2026-09-17 (UTC+8)

近日，在科睿唯安集团发布的2022年《期刊引证报告》中，由山东大学主办、山东大学科技期刊社与荷兰Wolters Kluwer (威科)集团合作出版，山东大学第二医院承办的国际英文学术期刊Current Urology（《当代泌尿学（英文）》ISSN 1661-7649）获得首个影响因子（Impact Factor）：1.6分，位于JCI分区Q3区。

▲

期刊封面展示

Current Urology（《当代泌尿学（英文）》）2020年入选山东大学“强刊兴学”计划，2022年入选首批中国机构主办海外科技期刊回归试点期刊，参照中国科技期刊卓越行动计划高起点新刊支持力度，并纳入卓越行动计划统筹管理，现已被Emerging Sources Citations Index (ESCI), PubMed, PubMed Central, Scopus, Ovid, DOAJ, Embase, Chemical Abstract Service(CAS)等20余家数据库收录。

杂志由中国工程院郭应禄院士、瑞典前泌尿外科主席Peter Ekman教授担任共同主编，上海交通大学附属上海市第一人民医院夏术阶教授、山东大学第二医院唐东起教授担任共同执行主编，山东大学易凡教授、海口市人民医院白志明教授、山东省立医院吕家驹教授、北京大学第一医院李学松教授等担任副主编。由45名来自世界十多个国家和地区的高影响力学者组成国际化编委会，并组建起拥有22名学者的青年编委团队，旨在为全球泌尿外科专家学者搭建一流的学术交流平台，着力解决当代泌尿外科领域前沿热点与难点问题。

自2007年创刊以来，期刊共收到来自57个国家和地区的2000余篇稿件，稿源丰富，国际化程度高，其中投稿最多的前两位为美国（17.5%）和英国（13.1%），具有很高的学术水平。期刊的拒稿率在70%以上，保证了发表文章的学术质量。杂志聚焦泌尿系肿瘤、泌尿系结石、COVID-19 and Urology等热点方向组织多期专题并通过各种形式大力宣传，大大提升了文章的国际影响力，其中单篇文章最高访问量8000余次。杂志最新h指数为17，2022年度CiteScore为2.5。
